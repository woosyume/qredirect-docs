Questions

How do I allow screen access?
Open macOS System Settings → Privacy & Security → Screen Recording (or Screen & System Audio Recording) and enable QRedirect. This permission is used for still-image QR recognition, not video or audio recording. You can turn it off in the same place.
I allowed Screen Recording and nothing happens.
After allowing screen access, quit QRedirect from its menu bar menu and reopen it if the permission has not taken effect. You can also use Restart QRedirect in the welcome window.
Can I use a different shortcut?
Yes, in Settings. The default is ⌥Q. If a shortcut doesn't respond, something else is probably using it.
How do I get rid of the overlay?
Press Esc, press the scan shortcut again, or select a code to end scanning and close the overlay.
How do I delete recent history?
Recent history is on by default and stores up to 30 codes you open or copy, excluding all Wi-Fi QR codes. Turning history off leaves existing entries; use Clear History in Settings to delete them.
